## 논의 내용

기술 스택 선정 논의. 적은 의존성, 적정기술을 기준으로 선정하였다.

- 우아함 = 적정기술 = 문제에 딱 맞는 기술
- 의존성 최소화 원칙 적용
- UNIX 철학 기반: 각 컴포넌트가 한 가지 일만 잘 할 것

## 결정 사항

- 언어: Python
- Stream 수신: `sseclient` + `requests`
- 스트림 처리: `asyncio` (Python 내장)
- Symbolic Rule Engine: Pure Python (의존성 제로)
- ML 모델: `XGBoost`
- 벡터 검색 (RAG): `FAISS`
- 데이터 저장소: `SQLite`
- 대시보드: `Streamlit`
- 컨테이너화: `Docker`

의존성 전체 목록: `sseclient-py`, `requests`, `xgboost`, `faiss-cpu`, `streamlit`
